# Learnex – Smart Educational Platform

Learnex is a full-stack educational platform designed to provide
students with an interactive learning environment.

## 🚀 Live Demo

https://learnex-2-0.vercel.app

## 📂 GitHub Repository

https://github.com/PritamBhunia04/Learnex-2.0

## ✨ Features

- Student registration and login
- Instructor login
- Course browsing
- Course details
- Study materials
- Doubt Box
- Notifications
- Scholarship section
- Student dashboard
- Authentication
- MongoDB database integration

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- bcrypt

### Deployment
- Vercel — Frontend
- Render — Backend
- MongoDB Atlas — Database
